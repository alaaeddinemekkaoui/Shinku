# 🔥 About Project Phoenix

**Version:** 0.1  
**Created:** January 2026  
**Language:** 100% Rust

## What is Project Phoenix?

A lightweight, native text editor written entirely in Rust. Named after the mythical phoenix (and inspired by Final Fantasy and Zelda because why not!).

## Philosophy

- **Fast:** Native UI, no Electron bloat
- **Simple:** Clean code that's fun to work on
- **Fun:** Built while learning Rust

## Tech Stack

- **Language:** Rust
- **UI Framework:** Slint (native, declarative)
- **Text Buffer:** Rope data structure (ropey crate)
- **Architecture:** Clean layers (Core → App → UI → Platform)

## Current Features (v0.1)

✅ Basic text editing  
✅ Cursor movement  
✅ Undo/Redo  
✅ Save files  
✅ Keyboard shortcuts  

## Why Rust?

Because it's fast, safe, and actually fun to write. Plus the compiler is like a helpful friend who catches your mistakes.

## Why Not Electron?

- Electron "Hello World": 100+ MB
- Phoenix: 8 MB
- Electron startup: 1-2 seconds
- Phoenix: <200ms

Native is better. Fight me. 😎
